# 富文本代码生成器（TMP 风格）

给游戏聊天框生成 Unity **TextMeshPro 富文本**代码：**输入文字 → 勾样式 → 一键出代码**。

## 打开方式

**直接双击 `index.html`** —— 纯静态、零依赖，不需要起服务器。

> 注意：三个 `.mjs` 文件和 HTML 必须在同一目录下。页面用的是相对路径加载。

## 界面流程（从上往下四步）

1. **输入文字** —— 输入框里回车即换行，生成时自动转成 `<br>`。右侧实时显示字数 + 整段代码字符数。
2. **选择样式** —— 点一下选中（按钮打勾），再点一下取消：
   - **快捷组合**：金色加粗 / 只有颜色 / 大字警告 / 小字注释 / 全部清空
   - **文字样式**：加粗、斜体、下划线、删除线、全部大写、全部小写、下标、上标、小型大写、禁止换行
   - **颜色**：12 个常用色板 + 取色器 + 手填 HEX（支持 8 位带透明度）
   - **字号**：8 档预设 + 滑块/数字框（40–300，也可手填到 999）
   - **字距 / 行高**、**强调 / 装饰**（换字体、字重、半透明、等宽、插入空白）
   - **倾斜 / 位移**、**缩进 / 宽度**、**图标 / 链接**（表情图标、可点击链接）
   - 同类互斥项（全部大写 / 全部小写）自动二选一
   - **实测无效的标签不会出现在生成器里**，见下方「哪些标签已验证」
3. **已选样式** —— 一条条列出来，每条都能：
   - `×` 移除
   - `◀` `▶` 调整嵌套层级（**从左到右 = 由外到内**）
4. **生成结果**
   - **一键生成代码** + **复制**
   - **效果预览**：上面是模拟游戏聊天框的渲染效果，下面是上色后的原文，能看清每个标签的位置

## 关于生成结果

- 代码按 **「外层先写、内层后写」** 拼装，闭合标签自动倒序补齐。
  `颜色 + 字号 + 加粗` 且顺序为 `颜色→字号→加粗` 时，得到的就是最初那条：
  `<color=#e0b45e><size=100><b>滴滴滴</b></size></color>`
- `<size>` 是 TMP 点值，`100` = 原始大小。
- 颜色支持 `#RRGGBB`，也支持 `#RRGGBBAA`（末两位透明度）。
- 输入框里的 `<` `>` 会被转义成 `&lt;` `&gt;`，防止你的文字被当成标签解析；其余符号原样保留。
- 聊天框通常只放行部分标签，**被过滤的标签会原样显示成文字**。想知道某个标签在目标游戏里到底吃不吃，去 `lab.html` 逐个试最准。

## 为什么不使用 ES module（重要）

**`file://` 下浏览器会拦截 ES module。** Chrome / Edge 会把 `import "./lib.mjs"` 当成跨域请求，报：

```
Access to script at 'file:///.../lib.mjs' from origin 'null' has been blocked by CORS policy
```

结果是整段脚本不执行 —— 界面能看见，但"已选样式"是空的、按钮全都点不动（事件没绑上）。

所以这里改成**经典脚本 + UMD 全局对象**：

```html
<script src="lib.mjs"></script>
<script src="compose.mjs"></script>
<script src="app.js"></script>
```

`lib.mjs` / `compose.mjs` 用 UMD 包装，一份源码同时满足两种环境：

| 环境 | 加载方式 | 结果 |
|---|---|---|
| 浏览器 | `<script src>`（没有 `module`） | 挂到 `globalThis.RTLib` / `RTCompose` |
| Node 测试 | 测试里 eval 同一份源码 | 取同一个全局对象 |

> 文件名后缀 `.mjs` 是因为 Node 测试文件用 `import` 引用它们；在浏览器里它们是被当普通脚本执行的。真实原因是：**不要用 `type="module"`，也不要写 `import`** —— `selftest-pages.mjs` 里有一条回归测试专门盯着这点。

## 移动端

两个页面都做了响应式，断点与要点：

| 断点 | 处理 |
|---|---|
| `pointer:coarse` / `hover:none` | 触屏设备：按钮、色块、chip 全部加大到 ≥44px 可点；滑块轨道加高；输入框顶到 16px |
| ≤900px | 实验室的左右分栏改成上下单列，解除整页固定高度（避免嵌套滚动） |
| ≤780px | 生成器的「代码 / 预览」两栏折叠为单列；滑杆独占一行 |
| ≤640px | 表单标签换行置顶；参考表卡片改上下排列，代码块允许折行不再撑宽 |
| ≤420px | 进一步压缩字号与内边距；滑杆换行；手填 HEX 独占一行 |
| 横屏矮窗口 | 收窄上下留白，输入框降低最小高度 |

另外：

- `viewport-fit=cover` + `env(safe-area-inset-bottom)`：适配刘海屏和底部小白条
- `<meta name="color-scheme" content="dark">`：避免移动端深色页面出现白底闪烁
- **输入框统一 ≥16px**：iOS Safari 对小于 16px 的输入框会在聚焦时强制放大整个页面
- `body{overflow-x:hidden}` + `img,svg,table,pre{max-width:100%}`：横向溢出保险丝

自检里有 4 条静态断言盯着这些点（viewport 声明、断点存在、触屏适配、宽度保险），改坏了会被测出来。

> 说明：本机沙箱不允许启动无头浏览器（Chrome 的 IPC 需要命名管道，被安全策略拒绝），所以移动端是靠**静态审计 + 断言**保证的，没有真机截图。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | **生成器**（主入口） |
| `app.js` | 生成器页面逻辑（经典脚本，不用 module） |
| `lab.html` | 标签实验室：37 个 TMP 标签的逐个试玩 + 白名单过滤模拟 |
| `lib.mjs` | 共享库（UMD）：标签表、解析器、渲染器、语法高亮 |
| `compose.mjs` | 生成器核心（UMD）：`compose(文字, 顺序, 勾选, 参数)` → 代码 |
| `test-helpers.mjs` | 测试辅助：UMD 加载器 + DOM 桩 |
| `selftest-compose.mjs` | 生成逻辑测试（28 项） |
| `selftest-lib.mjs` | 解析/渲染层测试（25 项） |
| `selftest-pages.mjs` | 页面测试（27 项）：按 HTML 的脚本顺序真跑两个页面 + `file://` 兼容性回归 |
| `check.ps1` | 一键跑全部：语法检查 + 三套测试 |

`lib.mjs` / `compose.mjs` 是**唯一真值源**，页面和测试都加载同一份文件，没有各自复制解析器 —— 改一处两边都生效。

## 自检

```powershell
powershell -ExecutionPolicy Bypass -File .\check.ps1
```

共 80 项断言，全绿。其中这几条是踩过的坑留下来的回归测试：

- `index.html / lab.html 没有 type="module" 脚本`
- `index.html / lab.html 没有 import 语句`
- `页面暴露了 __composer（说明脚本执行到了末尾）` —— 脚本中途挂掉就没人设置这个全局
- `每种样式的闭合标签都正确（27 种）` —— 防止再生成 `</color=#fff>` 这种带属性的闭合标签
- `复现原始例子` —— 防止标签嵌套顺序被写反

## 哪些标签已验证

目标游戏的聊天框只放行一部分标签。目前实测结果：

| 标签 | 状态 |
|---|---|
| `<color=#e0b45e>` | **可用**（最初那条消息验证过） |
| `<size=100>` | **可用** |
| `<b>` | **可用** |
| `<gradient>` | **无效** —— 需要客户端有同名渐变预设，已从生成器移除 |
| `<mark>` | **无效** —— 已从生成器移除 |
| 其余标签 | **未实测**，勾之前建议先去 `lab.html` 逐个试 |

> 用法：在 `lab.html` 里发一条**只带单个标签**的短消息，看三种结果 —— ① 渲染出效果 = 放行；② 原样显示 `<mark=x>` = 未过滤但不支持；③ 整条消失 = 被服务端过滤。

移除一个标签要改 3 处（生成器标签表、页面控件、事件绑定），所以 `check.ps1` 里有回归测试盯着：页面控件不得存在、`app.js` 不得引用、勾满全部样式也产不出该标签。再发现无效标签，说一声即可，改完测试会自动验证。

## 无法 1:1 复现的部分（仅限标签实验室）

浏览器没有 TMP 渲染器，实验室页面里这几个标签只能视觉近似：`<sprite>`（画成带名字的色块）、`<style>`（加粗+字距近似）、`<pos>` / `<rotate>`（整段处理而非逐字）。其余标签在浏览器里与 TMP 语义一致。

**已从生成器移除的标签**（`<gradient>`、`<mark>`）仍留在 `lab.html` 的参考表里，仅作说明 —— 实验室是标签百科，生成器只放实测能用的。
