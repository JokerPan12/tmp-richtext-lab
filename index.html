使用要点

· 一条消息可以由多个片段拼成，每段自己的颜色/字号/加粗/斜体，能做出「白 + 红 + 青」这种分段效果。
· 默认字号 16、默认颜色白色；没单独设过的片段就用这两个值。
· 代码已按「外层先写、内层后写」排好，片段内顺序固定为 size → color → b → i。
· <size> 是 TMP 点值，数值越大字越大；100 ≈ 常规大小，所以 <size=16> 的字会明显偏小。
· 颜色支持 #RRGGBB，也支持 #RRGGBBAA（末两位是透明度，00 全透明、FF 不透明）。
· 聊天框通常只放行部分标签，被过滤的标签会原样显示成文字。哪个不生效，去 标签实验室 逐个试最准。
· 片段里的 < > 会被自动转义，防止你的文字被当成标签；其余符号原样保留。
